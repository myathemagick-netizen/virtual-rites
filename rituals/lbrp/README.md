# LBRP media

Place rite-specific images, audio, muted videos and embedded GLB models here. Declare them in `assets` in `../lbrp.json`; `do: "media"` displays/plays them. `narration` and `descriptionAudio` select audio assets for a step. Shared spoken phrases live in `assets/narration/shared` and are indexed by `assets/narration/manifest.json`. See `docs/ritual-media.md`.
